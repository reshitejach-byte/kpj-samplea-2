A modern, professional website for SREE KPJ GEMS - Leading Astro Gemstore. This website showcases certified precious gemstones, astrology-based recommendations, and consultation booking services.

## 🌟 Features

- **Home/Hero Section** - Engaging landing page with animated gemstone display

- **Consultation Booking** - Form for booking astrology consultations

## 🚀 Getting Started

### Opening the Website
1. Open the `index.html` file in your web browser
2. No server required - works locally on your computer
3. Navigate using the menu or scroll through sections

### Using the Website

#### Booking Consultation
1. Scroll to "Consultation" section
2. Fill in your details:
   - Full Name
   - Email Address
   - Phone Number
   - Date of Birth
   - Preferred Consultation Time
   - Your Concerns/Questions
3. Click "Book Appointment"
4. Success notification appears

#### Contact Form
1. Scroll to "Contact" section
2. Enter Name, Email, and Message
3. Click "Send Message"

## 📊 Data Storage

The website stores consultation and contact form data in your browser's localStorage for demonstration. To integrate with Excel:
1. Open browser Developer Tools (F12 → Console)
2. Run: `console.log(JSON.parse(localStorage.getItem('consultations')))`
3. Copy the data to your Excel file
