📊 DATA EXPORT & EXCEL TROUBLESHOOTING GUIDE
=============================================

QUICK START
-----------
1. Open your website (index.html)
2. Click the LOCK icon (🔒) in the top right header
3. You'll see Admin Dashboard
4. Click "Export CSV" buttons to download Excel files

IMPORTANT NOTE
---------------
The data is stored in your BROWSER's local storage. 
This means:
✅ Data persists even after you close the browser
✅ Data stays on YOUR computer in the browser
✅ Each browser (Chrome, Firefox, etc.) has separate data
⚠️  Clearing browser cookies/cache will DELETE the data

HOW TO ACCESS ADMIN DASHBOARD
------------------------------
Option 1: Click the LOCK icon (🔒) in website header
Option 2: Open admin.html directly in browser
Option 3: Navigate to: yourfolder/admin.html

THE ADMIN DASHBOARD HAS 4 MAIN AREAS
------------------------------------

1. DEBUG TOOLS (Blue & Green buttons at top)
   - "Check Stored Data" - Shows how many records exist
   - "Generate Test Data" - Creates sample data to test exports
   
2. STATISTICS
   - Shows total number of consultations, messages, contacts
   
3. CONSULTATIONS TABLE
   - View all booking requests
   - Click row to see full details
   - "Export CSV" button - Downloads as Excel
   - "Clear All" button - Deletes all consultations
   
4. MESSAGES TABLE
   - View all contact form messages
   - Click row to see full details
   - "Export CSV" button - Downloads as Excel
   - "Clear All" button - Deletes all messages

EXPORTING TO EXCEL - STEP BY STEP
---------------------------------

Step 1: Go to Admin Dashboard (click 🔒 in header)

Step 2: Wait for data to load
   - You should see numbers in the blue statistics boxes
   - If you see 0s, it means no data has been submitted yet

Step 3: Click "Export CSV" button
   - For Consultations: Exports booking form data
   - For Messages: Exports contact form inquiries

Step 4: File will download automatically
   - Save location: Usually your Downloads folder
   - File name: consultations.xlsx or messages.xlsx

Step 5: Open in Excel or Google Sheets
   - Double-click the downloaded file
   - Opens with Microsoft Excel, LibreOffice, or Google Sheets

TROUBLESHOOTING
---------------

❌ PROBLEM: Admin Dashboard shows 0 records
   SOLUTION:
   → Check if forms have been submitted on the website
   → Click "Generate Test Data" button to create sample data
   → Then click "Export CSV" to test the export

❌ PROBLEM: Data doesn't appear after submitting form
   SOLUTION:
   1. After filling form, check for GREEN success message
   2. Click "Check Stored Data" button in Admin panel
   3. Browser console will show stored data (Press F12 to open)
   4. If still not working, your browser might be blocking storage
   
   FIX:
   - Check browser privacy settings
   - Disable ad blocker for this site
   - Try a different browser
   - Clear browser cache and try again

❌ PROBLEM: Excel file is blank
   SOLUTION:
   → Go back to Admin panel
   → Click "Check Stored Data" button
   → Check if records exist
   → Try "Generate Test Data" first to verify export works

❌ PROBLEM: Special characters not showing in Excel
   SOLUTION:
   → This is fixed! We added UTF-8 BOM encoding
   → Re-download the file (it should show correctly now)

❌ PROBLEM: File won't open in Excel
   SOLUTION:
   → The file is actually a .csv file (not .xlsx)
   → Open it with Excel: Right-click → Open With → Microsoft Excel
   → Or: Open Excel first, then File → Open → select the file
   → Or: Rename file from .xlsx to .csv (doesn't matter, same format)

TESTING THE SYSTEM
------------------

1. Go to Admin Dashboard
2. Click "Generate Test Data" button
   (Creates 2 sample consultations and 1 sample message)
3. Statistics should now show:
   - Total Consultations: 2
   - Total Messages: 1
4. Click "Export CSV" to download
5. Open file in Excel to verify it works

IMPORTANT: BACKUP YOUR DATA
---------------------------

The data is stored only in your browser's local storage!

To keep your data safe:
1. Regularly export and save the Excel files
2. Keep backup copies on your computer
3. Don't clear browser cache (will delete data)

To backup/transfer data:
1. Export both CSV files
2. Open in Excel
3. Save as Excel format (.xlsx) for permanent storage
4. Keep copies on cloud storage (Google Drive, Dropbox, etc.)

DATA PRIVACY
-----------
✅ All data stays on YOUR computer
✅ Not sent to any server
✅ Not shared with anyone
✅ Only stored in your browser

IF YOU SWITCH COMPUTERS
------------------------
The data stored on your original computer will not transfer!

Solution:
1. Export Excel files from old computer
2. Email or transfer files to new computer
3. No need to re-enter data in forms

CLEARING DATA
-----------
⚠️  WARNING: This will DELETE all data!

To delete all data:
1. Go to Admin Dashboard
2. Find "Clear All" button under each table
3. Click and confirm deletion
4. Data will be permanently deleted

To backup before clearing:
1. Click "Export CSV" to download Excel files
2. Save them to safe location
3. Then click "Clear All"

FREQUENTLY ASKED QUESTIONS
--------------------------

Q: Where is my data stored?
A: In your browser's localStorage (part of browser memory)

Q: Can I see the data without Admin panel?
A: Yes, open browser Developer Tools (F12) and check Application tab

Q: What if I use Private/Incognito mode?
A: Data will be deleted when you close the window

Q: Can I import Excel files back?
A: Not automatically, but you can copy-paste data back into forms

Q: Does data backup automatically?
A: No, you must manually export regularly

Q: Can multiple people use this?
A: Each person using their own browser/computer gets separate data

Q: Is there a cloud backup?
A: No, only browser local storage. Export files regularly!

TECHNICAL INFO
--------------
Data Format: JSON (JavaScript Object Notation)
Storage: Browser localStorage API
Export Format: CSV (Comma Separated Values)
Compatible Programs: Excel, Google Sheets, LibreOffice, Numbers

HOW DATA IS SAVED
-----------------
When you submit a form:
1. Data is collected from form fields
2. Stored in browser's localStorage
3. Given a timestamp
4. Can be exported as CSV

Data includes:
- Consultation form: name, email, phone, DOB, time, concerns, date
- Contact form: name, email, message, date

GETTING HELP
-----------
If export still doesn't work:

1. Check Console for errors:
   - Press F12 (Developer Tools)
   - Go to Console tab
   - Look for red error messages

2. Try Test Data:
   - Click "Generate Test Data" button
   - Try exporting test data

3. Try Different Browser:
   - Data is separate for each browser
   - Try Chrome, Firefox, or Edge

4. Clear and Reset:
   - Export current data (backup!)
   - Clear browser cache
   - Reload page and try again

5. Check Form Submission:
   - Submit a test form with your name
   - Watch for GREEN success message
   - Check Admin panel for the entry
