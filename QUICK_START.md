## ⚙️ Troubleshooting

### Website won't open
- Make sure you're opening `index.html` (not a folder)
- Try a different browser (Chrome, Firefox)
- Check if the file path is correct

### Forms not working
- Enable JavaScript in browser settings
- Try a different browser
- Clear browser cache (Ctrl+Shift+Delete)

### Data not showing in admin dashboard
- Use same browser where forms were submitted
- Open admin.html on same computer
- Try clearing browser cache (this deletes data!)

### Can't export to CSV
- Try different browser
- Check browser download settings
- Ensure popup blocker is disabled
