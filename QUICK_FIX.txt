🎯 QUICK FIX CHECKLIST - DATA NOT EXPORTING
============================================

✅ STEP 1: Submit a Test Form
   - Go to website homepage
   - Fill out "Book Appointment" form with your details
   - Click "Book Appointment" button
   - Look for GREEN success message at bottom right

❌ If NO green message appears:
   - Check that all fields are filled (red asterisks = required)
   - Try again with complete information
   - Check browser console (F12 → Console tab)

✅ STEP 2: Go to Admin Dashboard
   - Click LOCK icon (🔒) in top right of website
   - Or open: admin.html in your browser

❌ If admin page won't load:
   - Make sure admin.html is in the same folder as index.html
   - Clear browser cache and try again

✅ STEP 3: Check Statistics
   - Look at the blue boxes at top
   - Should show: "Total Consultations" with a number
   - If still showing 0, try next step

❌ Data shows 0? Try This:
   - Click green button: "Generate Test Data"
   - Blue boxes should now show numbers (2, 1, etc.)

✅ STEP 4: Export Excel File
   - Find "Export CSV" button under Consultations
   - Click it
   - File will download to your Downloads folder

❌ File didn't download?
   - Check browser's download blocker
   - Try a different browser
   - Make sure JavaScript is enabled

✅ STEP 5: Open in Excel
   - Find downloaded file (consultations.xlsx or messages.xlsx)
   - Double-click it
   - Should open in Excel with your data

❌ File won't open?
   - Try right-click → Open With → Excel
   - Or open Excel first, then File → Open
   - Try LibreOffice if Excel not available

⚡ FAST TROUBLESHOOTING
======================

Problem: Data not showing in admin
→ Solution: Click "Check Stored Data" button, look at console (F12)

Problem: Form doesn't save
→ Solution: Check for green success message after submit

Problem: Export file is empty
→ Solution: Submit form first, then export

Problem: Excel won't open
→ Solution: Try opening with different program

Problem: Data disappeared
→ Solution: You may have cleared browser cache (data is lost)
  → Always export and backup Excel files regularly!

⚠️  IMPORTANT REMINDERS
=======================

1. Data is stored ONLY in browser
   → Same browser = same data
   → Different browser = different data
   → Clear cache = data deleted

2. Backup your data!
   → Export Excel files regularly
   → Save them to safe location
   → Don't rely only on browser storage

3. Each device is separate
   → Phone has different data than laptop
   → Each browser has separate data
   → Export files to transfer between devices

4. Data persists after closing
   → Closing website = data stays
   → Closing browser = data stays
   → Only clearing cache deletes data

🔧 ADVANCED DEBUG
=================

Open Browser Console (F12 → Console):

Check stored data manually:
→ Type: localStorage.getItem('consultations')
→ Should show your JSON data

Check messages manually:
→ Type: localStorage.getItem('messages')
→ Should show your JSON data

Clear data manually:
→ Type: localStorage.clear()
→ Deletes ALL localStorage data (use with caution!)
