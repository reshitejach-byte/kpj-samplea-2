## 💾 Data Management

### How Data is Saved:
- Automatically stored in browser localStorage
- No server required
- Data persists between visits
- Only on this computer/browser

### Accessing Data:
1. Open `admin.html` to view all submissions
2. Click "View" to see details
3. Click "Export CSV" to download to Excel
4. Data appears in columns (Name, Email, Phone, etc.)

### Backup & Security:
- Export data weekly to Excel
- Keep backups on external drive
- Always have CSV exports saved
- Data is only local (not transmitted)
